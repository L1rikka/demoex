# demoex
**Шпаргалка по linux #5** 
```diff
+ hostnamectl set-hostname  #настройка имен топологии
+ apt-get update #Обновление пакетов
+ apt-get install NetworkManager-tui nano -y  #установка расширения для настройки сетевых интерфейсов и текстовых редакторов с помощью nano
+ nmtui #диалог NetworkManager с сетевыми  параметрами
+ sysctl net.ipv4.ip_forward # проверка включена ли маршрутизация между устройствами
- reboot #перезагрузка системы
- ip --br -c a #проверка сетевых интерфейсов UP или DOWN
- ip -c a #подробная информация о созданных интерфейсах
```
> [!IMPORTANT]
> По умолчанию роутеры принимают и обрабатывают пакеты только для себя. В домашней сети каждый роутер чужой для другого и их взаимодействие происходит через посредника (сервера, Peer-to-Peer, связывающие протоколы), но т.к у нас локальная сеть маршрутизатор должен передавать трафик из одной сети в другую мы на всех устройствах открываем файл -
> nano /etc/net/sysctl.conf > net.ippv4.forward меняем значение на 1 для обработки пакетов чужого роутера  
NOTE - BLUE, TIP - GREEN, IMPORTANT - PURPLE, WARNING - Yellow, CAUTION - Red   
> Коммутаторы не имеют возможности настраиваться на nmtui поэтому его нужно настраивать на виртуальном коммутаторе openvswitch для добавления ip адресов и синхронизации VLAN
```diff
+ ovs-vsctl add-br br0 #создание пустого виртуального коммутатора
- ovs-vsctl add-port br0 ens18 #добавление портов и интерфейсов на которых будут синхронизированны порты
+ ovs-vsctl set port ens18 trunks=100,200,300, #объявление порта транковым для перечисленных VLAN
- ovs-vsctl set port ens18 tag=100 #конфигурация как access-port и добавление tag
+ ovs-vsctl show #проверка настроек виртуального коммутатора
